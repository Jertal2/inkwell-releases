# Inkwell — installers

This repository holds the Windows installers for **Inkwell**, a desktop app for writing stories and building their worlds: manuscript, codex, maps, timeline, plot board and idea board in one place.

## Install

1. Open the [latest release](https://github.com/Jertal2/inkwell-releases/releases/latest).
2. Download `Inkwell-Setup-<version>.exe` and run it.
3. Windows may show a "Windows protected your PC" warning because the installer isn't code-signed. Choose **More info → Run anyway**.

## Updates

Inkwell checks this repository for new releases and updates itself. You can also check manually in **Settings → About → Check for updates**. Updates never touch your stories: they are stored only on your own computer.

This repository contains installers only. It does not contain source code or any user content.
